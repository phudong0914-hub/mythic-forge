## English

### What is this?

Mythic Forge is a Next.js App Router starter where every AI coding agent — Claude Code, Antigravity, Cursor, Command Code — reads **the same set of engineering rules** the moment you open the project. No more re-explaining your standards in every chat.

### What's inside

| File | Read by | Purpose |
|---|---|---|
| [`AGENTS.md`](AGENTS.md) | Antigravity, Cursor, Codex, and other `AGENTS.md`-aware agents | **Single source of truth** for all rules |
| [`CLAUDE.md`](CLAUDE.md) | Claude Code | Imports `AGENTS.md` (`@AGENTS.md`) |
| [`.commandcode/taste/taste.md`](.commandcode/taste/taste.md) | [Command Code](https://commandcode.ai) | Condensed mirror of the rules as a Taste profile |

The rules combine three layers:

1. **Sacred Laws** — six non-negotiables: no pseudocode, complete files, 4C review (Correctness, Completeness, Context-fit, Consequence), decisions in Markdown, UI/Logic/Data separation, and three clarifying questions before acting.
2. **Development lifecycle** — `DEFINE → PLAN → BUILD → VERIFY → REVIEW → SHIP`, adapted from [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills).
3. **Karpathy principles** — think before coding, simplicity first, surgical changes, goal-driven execution, from [forrestchang/andrej-karpathy-skills](https://github.com/forrestchang/andrej-karpathy-skills).

### Quick start

Requirements: Node.js 20+ and pnpm.

```bash
git clone <repo-url> my-project
cd my-project
pnpm install
pnpm dev
```

Open <http://localhost:3000>.

> **Note:** clone to a normal local disk. pnpm cannot create its symlinked `node_modules` on Google Drive virtual drives (`EISDIR ... symlink`). See [ADR 0001](docs/adr/0001-deny-unrs-resolver-build-script.md).

### Using with AI agents

- **Claude Code / Antigravity / Cursor**: just open the folder — the rules load automatically.
- **Command Code**:

  ```bash
  npm i -g command-code
  command-code          # on Windows PowerShell; elsewhere `cmd` also works
  npx taste list        # show the loaded taste packages
  ```

  Share your taste profile:

  ```bash
  npx taste push --all                   # push to commandcode.ai (requires login)
  npx taste pull username/project-name   # pull someone else's profile
  ```

### Customizing the rules

1. Edit [`AGENTS.md`](AGENTS.md) — this is the source of truth.
2. Mirror the change in [`.commandcode/taste/taste.md`](.commandcode/taste/taste.md) using the format `- Rule text. Confidence: 0.90` under a `# Category` heading.
3. Validate: `npx taste lint --all`.

> The block between `<!-- BEGIN:nextjs-agent-rules -->` and `<!-- END:nextjs-agent-rules -->` in `AGENTS.md` is regenerated by `next dev`. Don't edit it — add your rules below it.

## Tiếng Việt

### Đây là gì?

Mythic Forge là bộ khung Next.js (App Router). Ngay khi bạn mở dự án, mọi AI coding agent (Claude Code, Antigravity, Cursor, Command Code) đều đọc **cùng một bộ luật kỹ thuật**. Bạn không phải giải thích lại tiêu chuẩn của mình trong mỗi cuộc trò chuyện.

### Bên trong có gì

| Tệp | Agent đọc | Vai trò |
|---|---|---|
| [`AGENTS.md`](AGENTS.md) | Antigravity, Cursor, Codex và các agent hỗ trợ `AGENTS.md` | **Nguồn duy nhất** chứa toàn bộ luật |
| [`CLAUDE.md`](CLAUDE.md) | Claude Code | Nhập lại `AGENTS.md` (`@AGENTS.md`) |
| [`.commandcode/taste/taste.md`](.commandcode/taste/taste.md) | [Command Code](https://commandcode.ai) | Bản rút gọn của bộ luật dưới dạng Taste profile |

Bộ luật gồm ba tầng:

1. **Sacred Laws (Luật Tối Cao)**: Luật Hiện Thực, Luật Toàn Vẹn, Thẩm Định 4C, Giao Thức MD, Ranh Giới Thánh, Gương Socratic.
2. **Vòng đời phát triển**: `DEFINE → PLAN → BUILD → VERIFY → REVIEW → SHIP`, theo [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills).
3. **Nguyên tắc Karpathy**: nghĩ trước khi code, ưu tiên đơn giản, sửa đúng chỗ cần sửa, làm việc theo mục tiêu kiểm chứng được.

### Bắt đầu nhanh

Yêu cầu: Node.js 20+ và pnpm.

```bash
git clone <repo-url> my-project
cd my-project
pnpm install
pnpm dev
```

Mở <http://localhost:3000>.

> **Lưu ý:** hãy clone vào ổ đĩa thường trên máy. pnpm không tạo được `node_modules` (vốn dùng symlink) trên ổ ảo của Google Drive và sẽ báo lỗi `EISDIR ... symlink`. Xem [ADR 0001](docs/adr/0001-deny-unrs-resolver-build-script.md).

### Dùng với AI agent

- **Claude Code / Antigravity / Cursor**: chỉ cần mở thư mục, luật sẽ tự động được nạp.
- **Command Code**:

  ```bash
  npm i -g command-code
  command-code          # trên Windows PowerShell dùng lệnh này thay cho `cmd`
  npx taste list        # xem các taste package đang có
  ```

  Chia sẻ taste profile:

  ```bash
  npx taste push --all                   # đẩy lên commandcode.ai (cần đăng nhập)
  npx taste pull username/project-name   # kéo profile của người khác về
  ```

### Tùy chỉnh luật

1. Sửa [`AGENTS.md`](AGENTS.md). Đây là nguồn chính.
2. Cập nhật thay đổi tương ứng vào [`.commandcode/taste/taste.md`](.commandcode/taste/taste.md), theo định dạng `- Nội dung luật. Confidence: 0.90` nằm dưới một tiêu đề `# Category`.
3. Kiểm tra: `npx taste lint --all`.

> Khối nằm giữa `<!-- BEGIN:nextjs-agent-rules -->` và `<!-- END:nextjs-agent-rules -->` trong `AGENTS.md` được `next dev` tự sinh lại. Đừng sửa khối này, hãy thêm luật của bạn bên dưới nó.
